# Tasks

The single live task list. A task belongs here only if it traces to an approved requirement ([R1–R13](PRODUCT_CONSTITUTION.md#article-2-approved-requirements)), an accepted decision, or a defect that breaks one of them. Proposals that are not approved are not tasks.

Tasks are level 7 of the [authority hierarchy](PRODUCT_CONSTITUTION.md#article-4-authority-hierarchy) and never override a higher document. Work that depends on an open conflict stays Blocked until the conflict is resolved ([Article 5](PRODUCT_CONSTITUTION.md#article-5-resolving-conflicts)). A task that changes existing behaviour names that behaviour, the tests that cover it and the decision that allows the change ([Article 7](PRODUCT_CONSTITUTION.md#article-7-protecting-existing-behaviour)).

**Implementation resumed on 2026-10-01 ([DEC-006](DECISIONS.md#accepted-decisions)).** When a task is finished, record the evidence in [BUILD_STATUS.md](BUILD_STATUS.md), update the feature status documents and add a [changelog](../CHANGELOG.md) entry.

Status values: **Ready**, **Blocked** (waiting for a decision), **In progress**, **Done**.
